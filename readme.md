# PHP Practice

A small PHP practice project for learning and experimenting with core PHP concepts, Composer dependencies, and basic PHP exercises.

## Project Structure
```
```
text
PHP_Practice/
├── exercism/        # Exercism PHP practice exercises
├── php01basics/     # Basic PHP learning files
├── vendor/          # Composer dependencies
├── composer.json    # Composer package configuration
├── composer.lock    # Locked dependency versions
├── index.php        # Main entry point
├── info.php         # PHP environment information page
└── person.html      # Basic HTML file
```
## Requirements
git s
- PHP 5.6 or newer
- Composer

## Dependencies

This project uses Composer. The main dependency is:

- `mpdf/mpdf` - A PHP library for generating PDF files

## Installation

Clone the repository:
```
bash
git clone <repository-url>
cd PHP_Practice
```
Install Composer dependencies:
```
bash
composer install
```
## Running the Project

You can run the project using PHP’s built-in development server:
```
bash
php -S localhost:8000
```
Then open this URL in your browser:
```
text
http://localhost:8000
```
## PHP Info Page

To view PHP configuration details, open:
```
text
http://localhost:8000/info.php
```
## Practice Exercises

The project includes PHP practice exercises, including beginner-level examples and Exercism-style exercises.

Some exercises may be runnable directly from the command line, for example:
```
bash
php path/to/runner.php
```
## Notes

- The `vendor/` directory is generated by Composer and should generally not be edited manually.
- If dependencies are missing, run `composer install`.
- If `vendor/` is ignored by Git, other users can recreate it from `composer.json` and `composer.lock`.
